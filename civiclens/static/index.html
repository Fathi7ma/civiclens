How CivicLens works

  1. Classify. The question is matched to an intent and its location resolved to a real map point, using the city's geocoded address dataset.
  2. Query. Typed Socrata queries run against the city's own records. Spatially, intersects is used where available, with a locally verified point-in-polygon fallback.
  3. Cite. Every claim carries the reproducible query URL that produced it. No claim appears without one.
  4. Refuse. When the datasets cannot answer the question, CivicLens says so and names the gap instead of estimating. It will not recite setback or floor-area-ratio numbers from memory, because those live in the code, not in a model.
